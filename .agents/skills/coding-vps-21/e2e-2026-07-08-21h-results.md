## Lições Aprendidas (cross-rein)

1. **LiteLLM crashloop = Prisma schema não inicializado**: sempre rodar `prisma db push` no primeiro deploy com DB novo.
2. **Max tokens para MiniMax-M3 XMax Thinking = ~80-120 mínimo** (reasoning_tokens 23-55 já consumidos).
3. **Porta dos coding agents = 8001-8009** (não 8000), em swarm VIP. `published_port` não está configurado.
4. **Playwright headless_shell = instalar separado** do Chromium. `playwright install chromium-headless-shell` baixa ~2.3 MiB.
5. **Firecrawl RAM**: NUM_WORKERS_PER_QUEUE=2 + MAX_CONCURRENT_JOBS=2 + BROWSER_POOL_SIZE=2 = sweet spot para 15GB VPS.
6. **OOM cascade**: rodar 8 coding agents E2E em paralelo derruba LiteLLM. Fazer sequencial OU aumentar RAM da VPS.
7. **SSH Tailscale timeout = VPS OOM**: se SSH não responde, VPS está sobrecarregada. Aguardar 60-90s antes de retentar.
8. **OpenAPI schema dos agents**: `POST /chat?prompt=X&max_tokens=Y` (query params, NOT body).

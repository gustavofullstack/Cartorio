### Lessons Learned
- (lesson-2026-07-02-telegram) background_tasks.add_task do FastAPI NAO pode receber Session de
  Depends(get_db) — a Session e fechada antes da task rodar. Passar apenas refs a Redis/recursos
  sem DB.
- (lesson-2026-07-02-deploy) docker service update --env-add em servico com port mapping host pode
  falhar por conflito. Seguir AGENTS.md: scale 0 -> update -> scale 1.
- (lesson-2026-07-02-argilla) GRANTs faltando no schema public sao causa-raiz comum de CrashLoop
  em servicos que rodam Alembic. Diagnostico: 'permission denied for table alembic_version'.
- (lesson-2026-07-02-scripts) Scripts one-shot com LMDB direto (/etc/easypanel/data) sao uteis
  para migracao rapida mas nao devem ser commitados com senhas puras. Separar: config.json
  template + script que le env vars.
- (lesson-2026-07-02-cpu-saturao) CPU 100% em rolling restart de 10 servicos simultaneos gera
  load avg 15x em 4 cores. Esperado e transitorio. NUNCA e motivo para escalar ou reiniciar
  precipitadamente. Esperar 30min.
- (lesson-2026-07-02-chatwoot-bootstrap) Chatwoot install novo NAO cria bootstrap data — DB vazio
  + ENABLE_ACCOUNT_SIGNUP=false no DB (env var Docker nao eh respeitada se InstallationConfig tem
  valor diferente). Para bootstrap: rails runner com InstallationConfig.update(value: true),
  Account.create, User.create(type: SuperAdmin), AccountUser, Channel::Api, Inbox. Token via
  /auth/sign_in (nao Doorkeeper AccessToken diretamente, que exige application_id valido).

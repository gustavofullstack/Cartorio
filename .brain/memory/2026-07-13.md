## Lições aprendidas

1. **HOLD reportado ≠ HOLD real**: skill chatwoot mostrou token desatualizado,
   só validei extraindo token real via `rails runner`.
2. **DNS Easypanel interno não resolve do Mac local**: Tailscale ou container Swarm.
3. **Formato resposta Chatwoot inconsistente**: helper `_unwrap()` cobre 3 casos
   (top-level, `{payload: ...}`, `{data: {payload: ...}}`).
4. **Cleanup antes de POC**: `ensure_inbox()` criava duplicados durante testes.
   Adicionar idempotência real ou rodar cleanup antes.
5. **Custom attributes são o canal LGPD**: mascarar CPF/RG **sempre** no Chatwoot,
   audit log fica no backend via POST /api/v1/atendimentos.
6. **Token via env do container API pode estar rotacionado**: sempre ter fallback
   `CHATWOOT_TOKEN_FILE=/tmp/chatwoot_token` (chmod 600).

### 4. Paste accumulation workflow

Pasted-text files são salvos em `~/.zcode/tmp/paste-attachments/YYYY-MM-DD/`. Quando o conteúdo são múltiplas cópias do mesmo super-prompt:

1. **Verificar duplicação:** `md5 paste1 paste2` (MD5 diferentes mas texto redundante)
2. **Extrair conteúdo único:** a primeira parte de cada paste geralmente traz material novo (investigação focada, hipótese testável); o restante é reciclagem do paste anterior
3. **Consolidar em `prompts/*.md` no repo:** arquivo limpo, sem duplicatas, com referência cruzada ao prompt master
4. **Descartar duplicatas:** paste files podem ficar (são tmp), mas não virar conteúdo do repo

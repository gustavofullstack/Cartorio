## 2026-08-25 - DPO Dashboard Loading State & A11y
**Learning:** Async data fetches in administrative dashboards often lack user feedback during the request, and simple inputs are missing explicit labels, which hinders accessibility and usability. When implementing loading states on buttons, it's critical to use standard `disabled` attributes rather than inline CSS to maintain design consistency, and to always use `try...finally` blocks to ensure the UI recovers if the request fails.
**Action:** Enforce explicit `for` attributes on labels matching input `id`s, implement visual loading states via the native `disabled` attribute on action buttons to prevent double-clicks and provide immediate feedback, and always wrap async UI updates in `try...finally` to guarantee state reset. Focus should also be drawn to missing required fields.

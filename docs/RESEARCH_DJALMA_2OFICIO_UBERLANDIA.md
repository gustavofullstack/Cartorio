## 4. Guia de Integração & Contexto Operacional para o Bot Hermes

### 4.1 Regras Invioláveis de Resposta (P0 Security & Compliance)
1. **HITL (Human-in-the-Loop) Obrigatório**: O Bot Hermes responde autonomamente **apenas** a dúvidas institucionais, horários, localização, documentos necessários para triagem e estimativas de emolumentos fixos. Toda e qualquer intenção de lavratura de escritura, inventário, divórcio ou validação jurídica complexa deve gerar um atendimento em status `DRAFT` e disparar o **Handoff Humano no Chatwoot**.
2. **Proteção PII (LGPD)**: O agente jamais deve solicitar ou expor CPF, RG, CNH, dados bancários ou detalhes de partilha patrimonial em mensagens públicas. Todo texto recebido passa por PII scrubbing (3 camadas) antes de interagir com os modelos LLM.
3. **Auditability (Provimento 74 CNJ)**: Cada interação que envolve consulta de protocolo ou emissão de estimativa gera um registro com Hash Chain SHA256 + HMAC.

### 4.2 Arquitetura Técnica na VPS Hostinger
- **Provedor LLM**: MiniMax modelo `MiniMax-M3 XMax Thinking` via endpoint `https://api.minimax.io/v1`.
- **Chave de API em Produção**: Gerenciada estritamente via secret `MINIMAX_CODING_PLAN_KEY_API` no EasyPanel/Docker Swarm.
- **FastMCP Server**: 15 ferramentas nativas registradas na API FastAPI (`api.2notasudi.com.br`) para cálculo de emolumentos, consulta de protocolos, agendamentos e emissão de segunda via.
- **CRM & Canais**: Chatwoot 4.x (`chat.2notasudi.com.br`) com extensão `pgvector`, Evolution API 2.3.7 (`cartorio-2notas`) e Photon Gateway iMessage (`127.0.0.1:8793`).

## 2024-05-18 - Unsafe SSL Verification Disable (CWE-295)
**Vulnerability:** Found `verify=False` in `httpx.AsyncClient` initialization in `backend/app/api/v1/health_radar_expanded.py`.
**Learning:** Hardcoded SSL verification bypass (`verify=False`) was used for checking public domains. This exposes the application to Man-in-the-Middle (MITM) attacks and violates basic security standards, even in health checks for public domains. Memory explicitly stated: "When making HTTP requests, avoid disabling SSL certificate validation (verify=False) to prevent MITM vulnerabilities (CWE-295). Note that Traefik endpoints monitored in health_radar_expanded.py (e.g., *.2notasudi.com.br) are public internet domains and MUST use standard SSL validation (do not use verify=False), even if they are part of internal monitoring scripts."
**Prevention:** Always rely on default SSL certificate validation (`verify=True`). If testing internal self-signed endpoints, use proper CA bundles or isolated test environments instead of completely disabling validation in production code.

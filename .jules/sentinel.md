## 2024-11-20 - Timing Attack Vulnerability in Secret and Token Validation
**Vulnerability:** Simple string equality check (`==`) was used to validate cryptographic secrets and API tokens in `backend/app/services/audit_keys.py` and `backend/app/services/n8n_token_router.py`. This allows an attacker to potentially guess the secret/token by measuring the time it takes for the server to reject incorrect values (timing attack).
**Learning:** Python's standard string equality (`==`) returns early upon encountering the first mismatched character, meaning comparisons take slightly longer the more prefix characters match the true secret. Although minor, this is a known vulnerability for cryptographic checks and webhook validations.
**Prevention:** Always use `hmac.compare_digest(a, b)` when comparing cryptographic secrets, API keys, tokens, or webhook signatures. This function compares the values in constant time, preventing timing attacks. When using `hmac.compare_digest`, ensure both arguments are of the same type (both `str` or both `bytes`) and neither is `None`.

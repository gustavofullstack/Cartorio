## 2026-07-28 - [Refactor raw SQL strings for counting records to use SQLAlchemy func.count]
**Vulnerability:** Execution of raw SQL strings directly within Python functions via `text()` (e.g. `text(f"SELECT COUNT(*) FROM audit_log WHERE timestamp >= {ts_1d}")`). While the evaluated variables were derived from internal utilities, interpolating strings directly into SQL statements without bind parameters is an unsafe anti-pattern and a prevalent source of SQL Injection vulnerabilities.
**Learning:** This codebase previously relied heavily on `text(...)` for simple database queries like counting records because of perceived convenience across different SQL dialects. However, using SQLAlchemy's ORM capabilities (like `select(func.count()).select_from(...)`) is both dialect-agnostic and inherently safer against injections.
**Prevention:** Avoid injecting dialect-specific SQL functions or expressions via f-strings. To ensure cross-dialect compatibility and prevent SQL injection, compute dynamic values like date offsets in Python (using `datetime` and `timedelta`) and pass them safely as bound parameters, or prefer using pure ORM operations like `func.count()`.

## 2025-02-14 - Fix Timing Attack Vulnerabilities in HMAC Verification
**Vulnerability:** The application was vulnerable to timing attacks during HMAC verification for LGPD export envelopes and audit logs because standard string equality (`==`) was used to compare signatures instead of a constant-time comparison function. This could allow an attacker to forge signatures by guessing the expected HMAC byte-by-byte based on the time it takes to reject invalid signatures.
**Learning:** Security-critical functions were using standard equality operators for sensitive data comparison. While `hmac` was imported, its `compare_digest` method was not uniformly applied across the codebase. In the `audit_integrity.py` file, the `hmac` module was imported as `_hmac` (`import hmac as _hmac`), which requires careful attention when applying fixes to avoid `NameError` exceptions at runtime.
**Prevention:** Always use `hmac.compare_digest` (or the appropriate alias if renamed) for comparing cryptographic hashes, signatures, and API keys to ensure constant-time comparison and prevent timing attacks. Enforce this via code review or static analysis tools.

## 2026-07-31 - Dashboard Keyboard Accessibility Constraint
**Learning:** The legacy dashboards (`user-review-dashboard` and `operations-dashboard`) use a pattern combining `:hover` and `:focus-visible` to apply `outline: none`. This completely removes keyboard focus indicators. Simply replacing `outline: none` with a visible outline in the combined rule breaks the mouse experience (by showing focus rings on hover). The dashboards are also regenerated via python scripts, meaning CSS fixes must be applied to the  source files, not the output  files.
**Action:** Always decouple `:focus-visible` from `:hover` rules when restoring focus indicators. Maintain `outline: none` on the combined or `:hover` rule, and append a specific `:focus-visible { outline: 2px solid var(--brand); }` rule immediately after. Ensure changes are made in the source `dashboard.py` scripts and re-run them with `uv run --with openpyxl python <script.py>`.

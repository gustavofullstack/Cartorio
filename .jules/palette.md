## 2026-07-06 - Keyboard accessibility and focus rings
**Learning:** Overriding focus rings with `outline: none` (or failing to provide explicit focus styles for interactive elements that might normally lack them in specific themes) harms keyboard accessibility. Relying only on background color changes for `:hover` and `:focus-visible` can provide insufficient visual cues for keyboard navigation, making it hard for users to determine which element has focus.
**Action:** When styling interactive elements like buttons, replace `outline: none` on `:focus-visible` states with clear, distinct focus rings. Ensure a high-contrast focus style, for example, `outline: 2px solid var(--brand); outline-offset: -2px;`, to maintain accessibility across themes and states while keeping the standard hover state separate.
